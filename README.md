# 💼 Portfolio Personal - Frontend

Este proyecto consiste en el desarrollo de un portfolio personal web como parte de las prácticas formativas de la carrera. El objetivo es crear una página que funcione como carta de presentación profesional, mostrando información personal, habilidades y formas de contacto.

## 🚀 Tecnologías utilizadas

* HTML5
* CSS3

## 📌 Características principales

* Estructura semántica con etiquetas modernas de HTML
* Estilado completo mediante CSS externo
* Uso de Flexbox para la distribución de elementos
* Diseño responsive adaptable a distintos dispositivos
* Secciones organizadas: Inicio, Sobre mí, Servicios, Tecnologías y Contacto
* Formulario de contacto (sin funcionalidad backend)
* Tabla personalizada para mostrar habilidades técnicas

## 🎯 Objetivo del proyecto

Aplicar los conocimientos básicos y avanzados de desarrollo frontend, incorporando buenas prácticas como el uso de CSS modular, diseño responsive y estructura de código limpia y mantenible.
